# ADR — Architectural Decision Records

Chaque fichier numéroté (`ADR-000N-sujet.md`) documente une décision d'architecture qui engage durablement le projet — contexte, décision, conséquences (ce qui devient plus facile, ce qui devient plus difficile) et marche arrière possible — à consulter avant de revenir dessus, pas seulement pour l'historique.
